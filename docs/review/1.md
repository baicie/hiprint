## P1-3：patch 机制有“跨 runtime 不重新应用”的隐患

你现在的 patch 机制使用模块级 `appliedPatches: Set<string>`。这在单页面单次加载时没问题，但有几个隐患：

```txt
1. force reload 后 patch 不一定重新应用
2. 测试里更换 window/mock runtime 后，patch 可能被跳过
3. runtime snapshot 只会在第一次 patch 时写入
4. 多个 legacy runtime 共存时无法区分
```

建议把幂等标记挂到 runtime/window 上，而不是模块级全局 Set。

可以改成：

```ts
const PATCH_STATE_KEY = "__HIPRINT_RE_APPLIED_PATCHES__";

declare global {
  interface Window {
    __HIPRINT_RE_APPLIED_PATCHES__?: Set<string>;
  }
}

export function applyLegacyPatches(runtime: LegacyRuntime): void {
  const win = runtime.rawWindow;
  const applied = win.__HIPRINT_RE_APPLIED_PATCHES__ ?? new Set<string>();

  win.__HIPRINT_RE_APPLIED_PATCHES__ = applied;

  for (const patch of patches) {
    if (applied.has(patch.name)) continue;
    patch.apply({ runtime, appliedPatches: applied });
    applied.add(patch.name);
  }
}
```

并且 `runtime-probe` 这种 patch 我建议不要只跑一次，snapshot 应该每次 load 后都能刷新。可以给 patch 加配置：

```ts
export interface LegacyPatch {
  name: string;
  once?: boolean;
  apply(ctx: LegacyPatchContext): void;
}
```

然后：

```ts
if (patch.once !== false && applied.has(patch.name)) continue;
```

`runtime-probe` 设置为：

```ts
once: false;
```

## P1-4：`loadScript` 对“正在加载中的 script”处理不够严谨

当前思路是：

```ts
const existing = document.querySelector(...)
if (existing) resolve()
```

这个有问题：
如果 script 标签已经插入，但还没加载完成，第二次调用会直接 resolve，导致后续认为 runtime 已经可用。

建议维护 `scriptPromises`：

```ts
const scriptPromises = new Map<string, Promise<void>>();

function loadScript(src: string, force = false): Promise<void> {
  if (!force && scriptPromises.has(src)) {
    return scriptPromises.get(src)!;
  }

  const promise = new Promise<void>((resolve, reject) => {
    if (force) {
      document
        .querySelectorAll(`script[data-hiprint-legacy-src="${src}"]`)
        .forEach((node) => node.remove());
    }

    const existing = document.querySelector<HTMLScriptElement>(
      `script[data-hiprint-legacy-src="${src}"]`,
    );

    if (existing?.dataset.loaded === "true") {
      resolve();
      return;
    }

    const script = existing ?? document.createElement("script");
    script.src = src;
    script.async = false;
    script.dataset.hiprintLegacySrc = src;

    script.onload = () => {
      script.dataset.loaded = "true";
      resolve();
    };

    script.onerror = () => {
      scriptPromises.delete(src);
      reject(new Error(`[hiprint-re] Failed to load legacy script: ${src}`));
    };

    if (!existing) {
      document.head.appendChild(script);
    }
  });

  scriptPromises.set(src, promise);
  return promise;
}
```
