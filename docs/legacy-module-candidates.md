# Legacy Module Candidates

This document tracks candidate modules discovered from static scan and runtime probe.

## Core candidates

These should eventually move into `@hiprint-re/core`.

- Template model
- Paper model
- Panel model
- Print element model
- Field binding
- Style options
- Serialization

## DOM candidates

These should eventually move into `@hiprint-re/dom`.

- Preview renderer
- Browser print
- HTML generation
- DOM mounting
- iframe/window preview

## Designer candidates

These should eventually move into `@hiprint-re/designer`.

- Selection
- Drag
- Resize
- Keyboard shortcuts
- History
- Property panel bridge

## Legacy-only candidates

These should stay in `@hiprint-re/legacy`.

- jQuery compatibility
- Global patches
- Old plugin registration behavior
- Runtime shims
